# Excel Financial Modelling Tutor

A Claude skill that teaches you to build a full **3-statement model and DCF** yourself, live in Excel, through a fixed 89-step scripted course on a practice company (Kaveri Foods Ltd).

Claude sets up the workbook, highlights where to work, asks one step at a time, checks your formula, and moves on. You type every formula.

## Modules

0 Setup · 1 Historicals · 2 Ratios · 3 Assumptions · 4 Revenue to EBITDA · 5 Working capital · 6 Fixed assets · 7 Debt · 8 Profit · 9 Cash flow · 10 Balance sheet · 11 DCF valuation · 12 Sensitivity

## Install

- **Claude Code:** copy the `excel-financial-modelling-tutor/` folder into `~/.claude/skills/`.
- **Claude.ai:** zip the `excel-financial-modelling-tutor/` folder and upload it under Settings → Capabilities → Skills.

Works best with the Claude for Excel add-in. Then say: *"Start the financial modelling course."*
